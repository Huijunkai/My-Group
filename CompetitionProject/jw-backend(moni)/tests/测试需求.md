## 概述

### 项目背景

JW-Backend (moni) 是一个教务系统后端模拟服务，为前端应用提供模拟数据接口。测试模块旨在确保各个功能模块的正确性、稳定性和性能。

### 测试目标

- ✅ 验证 API 接口的功能正确性
- ✅ 确保数据结构的完整性和一致性
- ✅ 测试异常处理和边界条件
- ✅ 评估系统性能表现
- ✅ 保障代码质量和可维护性

### 技术栈

- **测试框架**: Mocha
- **断言库**: Node.js Assert
- **运行环境**: Node.js
- **测试类型**: 单元测试、集成测试

## 测试策略

### 测试金字塔

```
        /\
       /  \
      / UI \          (未来扩展)
     /------\
    / 集成测试 \       (API 模块测试)
   /----------\
  /  单元测试   \      (数据模块测试)
 /--------------\
```

### 测试原则

1. **AAA 模式**
   - **Arrange (准备)**: 准备测试数据和环境
   - **Act (执行)**: 执行被测试的代码
   - **Assert (断言)**: 验证结果是否符合预期

2. **测试独立性**
   - 每个测试用例应该独立运行
   - 不依赖其他测试用例的执行结果
   - 测试之间不应该有副作用

3. **测试命名规范**
   - 使用中文描述测试场景
   - 使用标签分类：【正常输入】、【异常输入】、【边界值】等
   - 清晰表达测试意图

4. **测试覆盖**
   - 正常流程测试
   - 异常流程测试
   - 边界条件测试
   - 性能测试

## 最佳实践

### 测试编写规范

#### 1. 测试文件命名

```
test.<模块名>.js
```

示例:
- `test.auth.js` - 认证模块测试
- `test.student.js` - 学生数据模块测试

#### 2. 测试结构

```javascript
describe('模块名称 - 模块描述', () => {
    describe('函数名() - 测试类型', () => {
        it('【测试分类】测试描述', async () => {
            // Arrange - 准备
            const input = 'test';
            
            // Act - 执行
            const result = await functionToTest(input);
            
            // Assert - 断言
            assert.strictEqual(result.expected, 'value');
        });
    });
});
```

#### 3. 测试分类标签

- 【正常输入】- 正常业务流程测试
- 【异常输入】- 异常情况处理测试
- 【边界值】- 边界条件测试
- 【性能】- 性能相关测试
- 【数据一致性】- 数据一致性验证
- 【数据有效性】- 数据有效性验证
- 【字段完整性】- 字段完整性验证
- 【返回值验证】- 返回值结构验证
- 【业务逻辑】- 业务逻辑验证
- 【安全性】- 安全性验证

#### 4. 断言最佳实践

```javascript
// ✅ 好的断言
assert.strictEqual(result.success, true, '登录应该成功');
assert.ok(result.data, '数据不应该为空');
assert.ok(Array.isArray(result.items), '应该是数组');

// ❌ 避免的断言
assert(result.success); // 缺少错误消息
```

#### 5. 异步测试

```javascript
// ✅ 使用 async/await
it('应该返回学生信息', async () => {
    const result = await getStudentInfo(cookies);
    assert.ok(result);
});

// ✅ 设置超时时间
it('性能测试', async () => {

```

## 附录

### 常见问题

#### Q1: 测试失败如何调试？

```bash
# 运行单个测试并查看详细输出
npx mocha tests/test.auth.js --grep "特定测试" --reporter spec

# 使用 Node.js 调试器
node --inspect-brk node_modules/.bin/mocha tests/test.auth.js
```

#### Q2: 如何处理异步测试超时？

```javascript
// 增加超时时间
it('长时间测试', async () => {
    // ...
}).timeout(10000); // 10秒
```

#### Q3: 如何跳过某些测试？

```javascript
// 跳过整个测试套件
describe.skip('暂时跳过的测试', () => {
    // ...
});

// 跳过单个测试
it.skip('暂时跳过的测试用例', () => {
    // ...
});
```
