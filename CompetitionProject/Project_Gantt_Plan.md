# 青序项目甘特图计划（模拟数据模式）

## 项目概述
- 项目名称: 青序 - 智慧校园服务应用
- 项目周期: 8周 (2026年4月25日 - 6月20日)
- 团队规模: 4人
- 数据模式: 模拟数据 + API绑定对接

## 项目现状
- 后端(jw-backend): 模拟数据API已完成
- 前端(qinxu): 功能页面已完成，API客户端已完成
- 核心任务: 前后端API绑定联调 + 赛事文档

## 团队分工
- **成员A**: 后端负责人 (Node.js, Express, 模拟API)
- **成员B**: 前端负责人 (HarmonyOS/ArkTS, API对接)
- **成员C**: 文档与测试负责人 (赛事文档, 测试用例)
- **成员D**: AI功能与集成负责人 (AI功能, 性能优化)
